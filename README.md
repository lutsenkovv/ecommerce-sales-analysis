# ecommerce-sales-analysis
Exploratory Data Analysis and Power BI Dashboard for E-commerce Sales Data
##  Огляд проєкту
Цей проєкт присвячений комплексному аналізу продажів інтернет-магазину (Superstore Sales Dataset). Метою проєкту є виявлення ключових трендів у продажах, оцінка ефективності товарних категорій та створення інтерактивного дашборду для прийняття бізнес-рішень.

---

## Використані інструменти та технології
* **Мова програмування:** Python 3
* **Аналіз та очищення даних:** Pandas
* **Візуалізація даних у Python:** Matplotlib, Seaborn
* **Середовище розробки:** VS Code (Jupyter Notebooks)
* **BI-візуалізація:** Microsoft Power BI Desktop

---

## Етапи роботи з даними

1. **Exploratory Data Analysis (EDA):**
   * Первинне знайомство зі структурою даних та перевірка типів.
   * Виявлення пропущених значень та перевірка на наявність дублікатів.

2. **Очищення та трансформація даних (Data Cleaning):**
   * Конвертація текстових дат у формат `datetime`.
   * **Feature Engineering:** створення додаткових аналітичних колонок `Year` (Рік) та `Month` (Місяць).
   * Корекція типів даних для числових показників (`Sales`).
   * Експорт оброблених даних у файл `train_1.csv`.

3. **Аналіз бізнес-показників:**
   * Оцінка загального виторгу та середнього чека.
   * Аналіз розподілу продажів за категоріями (`Category`) та підкатегоріями (`Sub-Category`).
   * Дослідження динаміки продажів по роках.

---

## Результати та Візуалізація

### 1. Інтерактивний Power BI Дашборд
На основі оброблених даних було побудовано дашборд у Power BI, який включає:
* **KPI Card:** загальний виторг компанії з можливістю фільтрації.
* **Slicer:** фільтр за роками для оперативної аналітики.
* **Bar Chart:** порівняльний аналіз продажів за категоріями товарів.

---

## Ключові висновки (Business Insights)
* **Найприбутковіша категорія:** Товари категорії *Technology* та *Office Supplies* генерують основну частку виторгу.
* **Динаміка:** Спостерігається стабільне зростання продажів із року в рік, із найвищими показниками у 2018 році.
